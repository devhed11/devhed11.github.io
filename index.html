Sales Dashboard

Live · Daily use Try live demo → View code →

Ties call-tracking data to CRM sales records so leadership can finally see which reps convert calls into customers.

The problem

Inbound calls lived in one system, actual sales and revenue in another. Measuring rep performance meant hand-reconciling spreadsheets every month, and by the time anyone saw the numbers they were stale.

The build

A service that syncs both APIs every night, phone-matches callers to customers, and attributes revenue by rep, service line, and lead source — with seasonally-adjusted forecasting and role-based accounts so reps see their own numbers and admins see everything.

  • Replaced a monthly manual reconciliation with a live, nightly-refreshed dashboard
  • Per-rep, per-service, and per-source conversion and revenue tracking
  • Seasonally-adjusted forecasting against a Midwest demand curve

InventorySystem

Live · Daily use Try live demo → View code →

Automatically deducts chemical and equipment inventory as field jobs complete — no more guessing what's left on the truck.

The problem

Chemical and equipment inventory across 16+ field technicians was tracked by hand, with no reliable link between what a job actually used and what was left on the truck or in the warehouse.

The build

A sync pipeline that pulls completed jobs and product usage from the field-service platform daily, resolves real-world unit conversions, and deducts consumed product from each technician's truck automatically — with live stock visibility across two separate warehouse locations.

  • Automatic, job-linked deduction — replaced manual restock tracking
  • Per-technician truck inventory + dual-warehouse stock visibility
  • Separate handling for consumables vs. deployable vs. assigned equipment

FieldCall

Live · Weekly use Try live demo → View code →

Turns "everyone dial into the weekly call" into one phone number and a live attendance board.

The problem

Weekly field-team check-ins depended on someone manually calling around, or hoping the whole crew remembered to dial into a shared line at the right time.

The build

A Twilio-powered conferencing system — technicians dial one number and are auto-joined into that week's call, while a live dashboard resolves each caller to their name in real time. Calls record and transcribe automatically once they end.

  • One number replaces manual roll-call coordination every Monday
  • Live attendance dashboard, resolved from phone number to technician name
  • Automatic recording + transcription — a searchable record of every call
